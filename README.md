Sistema de Cadastro de Clientes

Sistema de cadastro de clientes em Python, executado no terminal. Projeto de estudo de POO (versão beta).

Funcionalidades
Cadastrar cliente (nome, e-mail, telefone e endereço)
Validação básica de e-mail e bloqueio de e-mail/telefone duplicados
Listar clientes cadastrados

Como executar
bash
python main.py

Status
Em desenvolvimento. Os dados ficam apenas em memória (são perdidos ao fechar o programa).
